# Задание

## Предметная область

Разработать простую программу-тайм-менеджер, которая поможет управлять временем и задачами. Программа должна позволять создавать задачи с описанием, устанавливать им сроки выполнения и приоритеты, а также отслеживать затраченное время на каждую задачу.

Дополнительные функции могут включать уведомления о приближении к дедлайнам, возможность создания ежедневного расписания работы и анализ времени, затраченного на различные задачи.

## Критерии модели данных

1. 5 или больше таблиц
2. Связи many-to-many и one-to-many
3. Ассоциативная сущность должна иметь поле, характеризующее связь, помимо ссылок на связанные таблицы

## Задание на 9 баллов

Реализовать на основании выбранной модели серверное приложение на FastAPI. Оно должно включать:

- [x] Таблицы, реализованные с помощью ORM SQLAlchemy с использованием БД PostgreSQL
- [x] API, содержащее CRUD. Там, где необходимо, реализовать GET-запросы, возвращающие модели с вложенными объектами (связи many-to-many и one-to-many)
- [x] Настроенную систему миграций с помощью библиотеки Alembic
- [x] Аннотацию типов в передаваемых и возвращаемых значениях в API-методах
- [x] Оформленную файловую структуру проекта с разделением кода, отвечающего за разную бизнес-логику и предметную область, на отдельные файлы и папки
- [x] *(опционально)* Комментарии к сложным частям кода

## Задание на 15 баллов

Реализовать функционал пользователя в разрабатываемом приложении:

- [x] Авторизация и регистрация
- [x] Генерация JWT-токенов
- [x] Аутентификация по JWT-токену
- [x] Хеширование паролей
- [x] Дополнительные API-методы для получения информации о пользователе, списка пользователей и смены пароля
