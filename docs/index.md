# Time Manager API

Отчёт по лабораторной работе: серверное приложение тайм-менеджера на **FastAPI** с хранением данных в **PostgreSQL**.

## О приложении

Программа помогает управлять временем и задачами. Пользователь может:

- создавать задачи с описанием, сроком выполнения и приоритетом
- группировать задачи по категориям и помечать тегами
- фиксировать время, затраченное на каждую задачу
- получать список задач с приближающимся дедлайном
- составлять ежедневное расписание
- смотреть аналитику по затраченному времени

Все операции, кроме регистрации и входа, доступны только авторизованному пользователю по JWT-токену. Каждый пользователь видит только свои данные.

## Стек технологий

| Технология | Назначение |
|------------|------------|
| FastAPI | Веб-фреймворк, маршрутизация, автодокументация Swagger |
| SQLAlchemy 2.0 | ORM - описание таблиц и работа с БД из Python |
| PostgreSQL | Реляционная база данных |
| Alembic | Система миграций схемы БД |
| Pydantic | Валидация входных и выходных данных, аннотация типов |
| python-jose | Генерация и проверка JWT-токенов |
| passlib + bcrypt | Хеширование паролей |
| Uvicorn | ASGI-сервер для запуска приложения |
